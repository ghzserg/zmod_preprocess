# Migrating Flash Studio Profiles to OrcaSlicer (Z-Mod)

This profile pack is a direct port of the original settings from **Flash Studio** to **OrcaSlicer** to ensure the best possible print quality.

> ⚠️ **IMPORTANT:** To ensure the profiles import correctly and remain fully editable or removable, **do not pack them into a single ZIP archive**. Please import the files one by one using the slicer menu. This prevents the creation of locked Bundle presets.

### Step-by-step Import Guide:

1. Download the profile files from the folders above (save them as individual `.json` files).
2. Open **OrcaSlicer**.
3. In the top-left menu, go to: **File** ➔ **Import** ➔ **Import config...**
4. Select and import the files one by one from each category:
   * **Printers** (from the `printer` folder)
   * **Processes/Quality** (from the `process` folder)
   * **Filaments** (from the `filament` folder)
5. Once all files are imported, they will appear under the **"User presets"** section. You will be able to fully customize, rename, or delete them at any time.

# Перенос профилей Flash Studio в OrcaSlicer (Z-Mod)

Этот набор профилей является точным переносом оригинальных настроек из **Flash Studio** в **OrcaSlicer** для обеспечения максимального качества печати.

> ⚠️ **ВАЖНО:** Чтобы профили импортировались корректно и их можно было легко редактировать или удалять, **не упаковывайте их в один ZIP-архив**. Импортируйте файлы по очереди через меню слайсера. Это позволит избежать создания заблокированных пакетных пресетов (Bundle presets).

### Пошаговая инструкция по импорту:

1. Скачайте файлы профилей из папок выше (сохраняйте их как отдельные файлы `.json`).
2. Откройте **OrcaSlicer**.
3. В верхнем левом меню выберите: **Файл** ➔ **Импорт** ➔ **Импортировать конфигурацию...**
4. Поочередно выберите и импортируйте файлы из каждой категории:
   * **Принтеры** (из папки `printer`)
   * **Процессы/Качество** (из папки `process`)
   * **Филаменты/Пластик** (из папки `filament`)
5. После импорта всех файлов они появятся в разделе **«Пользовательские профили»**. Вы сможете полноценно настраивать, переименовывать или удалять их в любой момент.
