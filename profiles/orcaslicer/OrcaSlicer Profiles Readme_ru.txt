Чтобы добавить эти профили в OrcaSlicer:
- Сначала необходимо добавить стандартные профили AD5X в OrcaSlicer (вы 
  должны добавить каждый размер сопла, который планируете использовать).
- Затем их можно импортировать через Файл -> Импорт -> Импорт конфигураций.
- Вы можете продолжать использовать свои существующие профили материалов и 
  процессов печати.

Отличия от стандартных профилей AD5X:
- Время разгона вентилятора установлено на 1.5 сек.
- Время пуска (kick-start) вентилятора установлено на 0.5 сек.
- Добавлен G-код zMod для начала, завершения и смены слоя.
- Стартовый G-код изменен для автоматической установки правильного режима 
  USE_TRASH_ON_PRINT.
- Добавлен G-код для смены филамента.
- Включена очистка в черновой башне (prime tower).
- Время загрузки филамента — 66 сек., время выгрузки — 0 сек.
- Тип Z-hop установлен на «нормальный» (normal).


G-коды начала печати и смены филамента настроены для поддержки режимов 
USE_TRASH_ON_PRINT=0 («режим без сброса» / nopoop mode) и USE_TRASH_ON_PRINT=2 
(«режим сброса под управлением слайсера»). По умолчанию параметры настроены 
для режима без сброса (nopoop mode).

Не забудьте вернуть настройку USE_TRASH_ON_PRINT к нужному значению после 
использования этих профилей. Это можно игнорировать, если вы планируете 
использовать данные профили для всех своих принтов (так как при следующей 
печати нужное значение все равно установится автоматически в самом начале).

В любом случае, объемы очистки будут определяться вашими настройками 
объемов смыва (Flush Volumes) в слайсере.


-= Требования для печати в режиме «Без сброса» (Nopoop) =-
Для использования режима без сброса должны быть выполнены все следующие 
условия:

1. «Wipe tower type» (Настройки принтера -> Мультиматериал) должен быть 
   установлен на «Type 2».
2. «Purge in prime tower» (Настройки принтера -> Мультиматериал) должен 
   быть включен.
3. Последовательность печати (Print sequence) должна быть «By Layer» 
   (По слоям), а не «By Object» (По объектам).
4. Не забудьте проверить объемы смыва (flush volumes).

Если хотя бы одно из этих условий не выполнено, профили вместо этого задействуют 
режим сброса под управлением слайсера.

Такие параметры, как «Purge to infill» (Очистка в заполнение), «Purge to this 
object» (Очистка в этот объект) и т.д., всегда будут работать корректно при 
использовании режима «Nopoop», при условии, что сам режим Nopoop работает 
правильно.


-= Требования для печати в режиме «Сброс под управлением слайсера» =-
Режим сброса под управлением слайсера активируется, если выполнено хотя бы 
ОДНО из следующих условий:

1. «Wipe tower type» (Настройки принтера -> Мультиматериал) установлен 
   на «Type 1».
2. «Purge in prime tower» (Настройки принтера -> Мультиматериал) отключен.
3. Последовательность печати (Print sequence) установлена на «By Object» 
   (По объектам).

(И не забудьте проверить объемы смыва!)

Опции вроде «Purge to infill» и т.д. будут корректно работать в режиме 
сброса под управлением слайсера только в том случае, если параметр 
«Wipe tower type» настроен на Type 1. В противном случае они будут вести 
себя некорректно.


-= Краткое резюме по «Purge to infill», «Purge to this object» и т.д. =-

Nopoop = ДА, вы можете использовать эти опции.
Сброс под управлением слайсера + wipe tower Type 1 = ДА, вы можете использовать 
эти опции.
Сброс под управлением слайсера + wipe tower Type 2 = НЕТ, эти опции будут 
работать некорректно.
