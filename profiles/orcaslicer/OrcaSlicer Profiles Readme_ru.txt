Чтобы добавить эти профили в OrcaSlicer:
- Сначала необходимо добавить стандартные профили AD5X в OrcaSlicer.
- Вы можете либо вручную поместить эти профили в директорию профилей OrcaSlicer.
- Либо добавить их в ZIP-архив, затем импортировать ZIP через Файл -> Импорт ->
Импорт конфигураций (File -> Import -> Import Configs).

Отличия от стандартных профилей AD5X:
- Время разгона вентилятора установлено на 1.5 сек.
- Время пуска вентилятора установлено на 0.5 сек.
- Интегрированы G-коды zMod для начала печати, завершения и смены слоя.
- Начальный G-код изменен для автоматической установки правильного режима
USE_TRASH_ON_PRINT.
- Добавлен G-код смены филамента.
- Включена функция очистки в черновой башне (Purge in prime tower).
- Время загрузки филамента установлено на 66 сек, время выгрузки — на 0.
- Тип Z-hop установлен на «Normal».

G-коды начала печати и смены филамента настроены на поддержку как режима
USE_TRASH_ON_PRINT=0 (nopoop mode), так и режима USE_TRASH_ON_PRINT=2
(slicer-controlled poop mode). Чтобы перейти в режим сброса под управлением
слайсера, отключите параметр «Purge in prime tower».

Обязательно верните значение параметра USE_TRASH_ON_PRINT к желаемому после
использования этих профилей. Вы можете игнорировать это, если планируете
использовать данные профили для всех своих отпечатков.

** Примечание по поводу функций «Purge to infill», «Purge to object» и т. д.: **
Эти настройки работают некорректно в режиме сброса (т. е. при отключенной функции
«Purge into prime tower») из-за ошибки в OrcaSlicer. Хотя часть пластика будет
«сброшена
